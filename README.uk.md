# Wavely

**Відкритий сервіс стрімінгу музики, створеної ШІ, який можна розгорнути самостійно.**
Подібно до Spotify, але кожен трек зроблено за допомогою ШІ (Suno, Udio, MusicGen, …), і біля нього показано промпт.

[English](README.md) · [API](docs/API.md) · [Розгортання](docs/DEPLOY.md) · [Архітектура](docs/ARCHITECTURE.md) · [Для операторів](docs/OPERATORS.md) · [Безпека](SECURITY.md) · [Участь у проєкті](CONTRIBUTING.md)

## Можливості

- **Прослуховування**: постійний плеєр із чергою, перемішуванням, повтором, гучністю, перемотуванням по хвилі звуку, гарячими клавішами та керуванням із екрана блокування. Працює на комп’ютері й телефоні.
- **Бібліотека**: вподобайки, публічні й приватні плейлисти з упорядкуванням, сторінки виконавців, жанри, повнотекстовий пошук за назвами, виконавцями, жанрами, промптами й текстами.
- **Завантаження**: MP3, WAV, FLAC, OGG, Opus, M4A та інші. Усе перевіряється ffprobe і перекодовується в MP3 192 кбіт/с (грає в усіх браузерах, точно перемотується), метадані видаляються, обчислюється хвиля звуку, обкладинки обрізаються до 640×640.
- **Лише ШІ-музика**: для кожного треку потрібен промпт чи опис і підтвердження, що трек створено ШІ та автор має право його публікувати. Біля треку показано ліцензію (комерційна / некомерційна).
- **Модерація**: поскаржитись може будь-хто (акаунт не потрібен, правовласники можуть залишити контакти). Модератори розглядають скарги, переглядають чергу схвалення, відновлюють вилучені треки й керують користувачами.
- **Приватність**: без електронної пошти, без стеження, без запитів до сторонніх сервісів (шрифти й бібліотеки роздаються з вашого сервера). Користувач може експортувати чи видалити всі свої дані.
- **Зручність розгортання**: один процес Node, один файл SQLite, одна тека для аудіо. Docker-образ, точка перевірки стану, коректне завершення, фронтенд без етапу збірки.
- **Доступність і дві мови**: інтерфейс англійською та українською, світла й темна теми, перевірки WCAG 2.2 AA (axe-core) у наборі тестів.

## Швидкий старт

Потрібні: Node.js ≥ 22 і `ffmpeg` (разом з `ffprobe` та кодувальником MP3, які є в стандартних збірках).

```bash
git clone <адреса-репозиторію> wavely && cd wavely
npm ci --omit=dev
npm start
# відкрийте http://localhost:3000 — перший створений акаунт стає адміністратором
```

Щоб побачити демо-вміст: `npm run seed` (створює користувача `demo` і шість згенерованих треків на запущеному сервері).

### Docker

```bash
docker compose up -d --build
# відкрийте http://localhost:3000
```

Дані зберігаються в томі `wavely-data` (змонтований у `/data`). HTTPS, зворотні проксі, резервні копії й оновлення описано в [docs/DEPLOY.md](docs/DEPLOY.md).

## Налаштування

Усе налаштовується змінними середовища, див. [`.env.example`](.env.example). Найважливіші: `BASE_URL` (публічна адреса; з `https://` вмикає Secure-cookie та HSTS), `REGISTRATION` (`open`, `invite`, `closed`), `UPLOAD_POLICY` (`users` або `admins`), `REQUIRE_APPROVAL` (перевірка модератором перед публікацією), `CONTACT_EMAIL` і `LEGAL_URL` (контакт для правовласників та ваші умови — обов’язково задайте для публічного сервера, див. [docs/LEGAL.md](docs/LEGAL.md)), `MAX_UPLOAD_MB`, `MAX_TRACK_MINUTES`, `TRUST_PROXY` (лише за власним проксі). Некоректні значення зупиняють сервер під час запуску з чітким повідомленням. Повна таблиця — в [англійському README](README.md#configuration).

### Адміністрування

- Перший акаунт на порожньому сервері стає адміністратором. Створити адміністратора можна з оболонки: `npm run create-admin -- <ім’я>`, пароль — у змінній `WAVELY_PASSWORD`. Якщо користувач забув пароль: `npm run reset-password -- <ім’я>` (див. [docs/DEPLOY.md](docs/DEPLOY.md)).
- Ролі: `user`, `moderator` (скарги, черга перевірки, вилучені треки), `admin` (все, зокрема керування користувачами).
- Скидання пароля поштою навмисно немає (пошта не збирається): адміністратор скидає пароль командою вище.

## Розробка й тести

```bash
npm ci
npm test            # API-тести: автентифікація, права, завантаження, стрімінг, пошук, модерація, безпека
npx playwright install chromium
npm run test:e2e    # справжній браузер: повні сценарії, доступність (axe-core), мобільна верстка, рестарти, обірвані завантаження, CLI
npm run dev         # перезапуск при змінах
```

Тести самі генерують аудіо й зображення через ffmpeg; нічого не завантажується.

## Обмеження

- Один процес сервера з локальною SQLite і локальним сховищем файлів. Для спільноти цього достатньо; горизонтального масштабування не передбачено.
- Немає федерації між серверами та функцій на основі пошти.
- Аудіо перекодовується в MP3 під час завантаження, оригінали не зберігаються.
- Програма не може визначити, чи трек справді створений ШІ і чи є в автора права. Вона вимагає декларацію, показує промпт і дає модераторам інструменти. Публічний сервер накладає юридичну відповідальність на оператора, див. [docs/OPERATORS.md](docs/OPERATORS.md).
